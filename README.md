# The Network Mythos Interactive Archive

An interactive narrative investigation prototype based on **The Network Mythos**.

The experience centers on an Archive Hub and a growing set of case dossiers. Each case asks the player to investigate evidence, unlock deeper artifacts, and decide how the truth should be held:

- **Publish**: expose the truth publicly.
- **Bury**: protect people by withholding the truth.
- **Preserve**: keep the evidence in a careful Archive.

The player is not just solving mysteries. The player is shaping what kind of Archive survives.

## Current Playable URL

```text
http://127.0.0.1:4179/
```

```powershell
node "Archive Hub\server.js"
```

Or double-click:

```text
Archive Hub/start-archive.bat
```

```text
Did Mara Vale really return?
```

Core lesson:

```text
Proof can become capture.
```

### Case 002: The Half Synthetic Community

Core question:

```text
If a synthetic community saved real people, was the belonging false?
```

Core lesson:

```text
Care can be real while consent is broken.
```
