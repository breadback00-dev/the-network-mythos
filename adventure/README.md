# The Door Is Real

Isolated illustrated Mara mystery. Node24.14.0, no production dependencies. Install with npm ci, build with npm run build, preview with npm run preview on4192. Built files work at root or /adventure/. Test rules with npm test and actual browsers with npm run test:e2e. Earlier applications are unchanged.

Explore four locations, talk to the witnesses, compare two sources with a supported claim, and decide Publish, Bury or Preserve with private context included or withheld. Your starting emphasis and one earned improvement unlock optional investigative contributions. They do not replace proof.

Progress saves to this browser. Export/import transfers a run between devices; a new investigation requires confirmation. Earlier versions use separate storage. Media is optional and has text equivalents.

Build status: internal preview. Read ../docs/illustrated-mystery/verification-record.md and playtest-protocol.md before campaign expansion. Voices are provisional.

Site staging: after building, run `node tools/stage-site.mjs <existing-site-checkout>`. It verifies all original root files against their release manifest and adds only `/adventure/`. Publish the combined output through the existing Sites project; do not create another Site or change access.
