## Saving future work

GitHub is the durable project record. Edit canonical plans in this directory, keep reviews in `docs/reviews/`, and keep prototype source and required media in their prototype directory. Commit and push completed, reviewed checkpoints on the active feature branch unless the user asks to pause publishing. Use Git history for iterations and update this index when the active plan changes.

Local output copies and downloadable packages are conveniences. They do not replace repository files or prove that a commit was pushed. Include the branch, commit, or pull-request link when reporting a saved checkpoint. Merging into the default branch remains a separate action.
