# Illustrated asset register

## Ownership and equivalents
All new art is generated with the built-in image-generation tool for this project from original prompts in art-direction.md. No real person likeness or commercial game assets supplied. Generated masters and prompts are project source, not a claim of exclusive copyright. Runtime scenes and expression sheets have descriptive alternatives.
Existing return.webm is original fictional Porchlight adaptation from source-assets/native-proof; preserve original master and captions. MP4 is a delivery rendition. Voices are provisional Windows speech synthesis, not final casting or imitation of a performer. Original dialogue and full transcript included.
Meme is original code-native SVG typography/composition with authored joke, cropped repost and source link; no live platform content.
## Integrated assets (7 September 2026)

- Four original scene masters: `source-assets/illustrated-mystery/{archive,porchlight,oracle,arbiter}.png`. WebP delivery renditions: `adventure/assets/scenes/`. Image-generation tool, original art-direction briefs; FFmpeg quality-78 format conversion only. The Arbiter composition includes the Warden silhouette.
- Five two-expression portrait masters: `source-assets/illustrated-mystery/{rafi,elian,mara,oracle-person,arbiter-person}.png`. WebP expression sheets: `adventure/assets/portraits/`. The UI crops the appropriate half of each sheet. These depict fictional people.
- `adventure/assets/media/return.webm` (457,916 bytes) and MP4 rendition (667,244 bytes). Existing fictional return video; MP4 produced with FFmpeg 9.0.1, H.264/yuv420p/AAC, fast-start. `return.vtt` retains the caption track.
- `elian.wav` (1,386,964 bytes) and `mara-old.wav` (851,394 bytes), generated with the preserved Windows speech-synthesis script `source-assets/illustrated-mystery/make-voices.ps1`. Provisional abridged performances with full text and transcripts, not final voice direction.
- `meme.svg` (843 bytes): original typographic joke with cropped-repost presentation and an equivalent description.

The build manifest records exact bytes and SHA-256 hashes for all delivered files. Scene compositions and the rendered Archive/Rafi and Archive/Elian views were visually inspected. Automated browsers decode, advance and seek the actual media; this does not establish human audibility, acting quality or perfect caption timing. Those remain playtest items.
