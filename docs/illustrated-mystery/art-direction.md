# Art direction and prompt masters

Original illustrated cyberpunk mystery. Painterly grain, crisp silhouettes, restrained dark teal and amber, warmth and unease. No borrowed franchise designs.
Four scene masters: Archive worn room/rain window/recorder/kettle; Porchlight rooftop cafe/lamps/plants/edited welcome; Oracle observatory/incomplete ring of blank panes; Arbiter symmetrical records hall/gold threshold/Warden silhouette.
Five expression-sheet masters: Rafi warm skeptical community advocate; Elian guarded protective brother; Mara warm ordinary recorded presence; Oracle porcelain/gold seams/translucent veil; Arbiter silver hair/precise formal robe. Each sheet has attentive and concerned expressions; CSS selects half without destructive cropping.
Built-in image generation used; generated originals copied to source-assets/illustrated-mystery. WebP renditions preserve composition. No text is baked into scene art. Source prompts and output provenance retained in asset-register.md.
Semantic controls carry action names; illustrations are atmosphere, not hidden-only navigation. Source descriptions carry all evidence. System serif/sans fonts, generous line spacing, visible keyboard focus, 200% reading size, reduced motion.
